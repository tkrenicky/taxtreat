# MLI partner-position source layout

This directory currently contains the Czech source-country partner-position source corpus (`cz_*`).

The Slovakia source-country package intentionally keeps its official MLI inventory provenance under `data/country_sources/sk_mli_inventory_source.json` while the Slovak package remains pre-release. Pair-specific Slovak MLI notice extraction and reconciliation live under the `data/legal_reviews/sk_outbound/` machine-review pipeline and are not production-approved legal conclusions.

Do not infer that the absence of `sk_*` files in this directory means Slovakia reuses the Czech MLI position corpus. Slovakia must use independently sourced Slovak MF / OECD evidence and its own pair-specific matching, reservations/options, and withholding-effective-date analysis.

Before Slovakia is promoted to a mature released source-country package, the source layout should either be migrated to a consistent per-country legal-source structure or this documentation should be retained as the canonical location rule.
