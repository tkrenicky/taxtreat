# TaxTreat

TaxTreat is a deterministic legal-rule and reporting engine for outbound withholding-tax analysis.

The current production legal release covers Czech-source outbound dividends, interest and royalties. The repository also contains the initial multi-country foundation for future source-country packages. Slovakia is registered as the second source-country package, but remains explicitly unreleased and fail-closed until its domestic rules, treaty network, MLI effects, compliance model and authoritative legal sources complete the same release gates used for the Czech implementation.

See `PROJECT_BIBLE.md` and `MILESTONES.md` for the wider project architecture and release history.
